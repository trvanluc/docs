# Thuật Ngữ & Giải Thích Khái Niệm Dự Án (Project Glossary)

Bảng thuật ngữ chuẩn hóa các từ khóa kỹ thuật và quản lý dự án được sử dụng trong toàn bộ tài liệu hệ thống **UniSupport**:

| Thuật Ngữ | Tên Đầy Đủ / Khái Niệm | Giải Thích Chi Tiết |
| :--- | :--- | :--- |
| **UniSupport** | University Support Platform | Nền tảng Web Application quản lý và xử lý yêu cầu hỗ trợ sinh viên tại Aurora University. |
| **Ticket** | Support Ticket / Phiếu hỗ trợ | Đơn vị dữ liệu đại diện cho một yêu cầu hỗ trợ do sinh viên gửi trên hệ thống. |
| **RBAC** | Role-Based Access Control | Cơ chế phân quyền dựa trên 3 vai trò: Sinh viên, Nhân viên, Quản lý. |
| **UAT** | User Acceptance Testing | Kiểm thử chấp nhận người dùng được thực hiện bởi Aurora University trong 10 ngày làm việc. |
| **SLA** | Service Level Agreement | Cam kết thời gian tối đa để xử lý một yêu cầu hỗ trợ. |
| **KPI** | Key Performance Indicator | Các chỉ số đo lường hiệu suất (Số Ticket mới, đang xử lý, quá hạn, điểm hài lòng). |
| **Audit Log** | Nhật ký tra soát | Bản ghi tự động lưu vết các thao tác quan trọng để phục vụ tra soát khi có sự cố. |
| **Responsive UI** | Responsive User Interface | Thiết kế giao diện tự động tương thích trên máy tính và thiết bị di động. |
| **Out of Scope** | Ngoài phạm vi dự án | Các hạng mục không thuộc cam kết triển khai trong hợp đồng 300 triệu / 14 tuần. |
