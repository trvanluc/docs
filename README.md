# UniSupport – Student Support Management System (Nhóm 3)

Bộ tài liệu dự án UniSupport: hệ thống web giúp sinh viên Aurora University gửi và theo dõi yêu cầu hỗ trợ, nhân viên các phòng ban tiếp nhận và xử lý, ban quản lý giám sát qua Dashboard và báo cáo. Dự án môn Software Project Management, lớp 261DICTSEB44038001.

- Tài liệu: bắt đầu từ [`docs/README.md`](docs/README.md) (mục lục, thứ tự đọc).
- Kế hoạch công việc: tab Issues và Milestones (`MS-01`…`MS-06`) của repo này; trạng thái task trên [GitHub Project UniSupport](https://github.com/users/trvannhan/projects/6) (Project đặt ở tài khoản trưởng nhóm vì GitHub không liên kết được Project cá nhân với repo của người khác).
- Mẫu issue (task, bug, feedback, change request) và mẫu PR: [`.github/`](.github/).
